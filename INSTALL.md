# Инструкция по установке Kapouch на Beget (без SSH)

Эта инструкция позволяет развернуть сервис Kapouch на shared-хостинге Beget **без SSH и без консоли**.

## 1. Подготовка файлов

1. Скачайте содержимое проекта Kapouch.
2. В файловом менеджере Beget откройте корень сайта (обычно это папка домена).
3. Загрузите в корень сайта **все файлы** проекта:

```
/index.php
/api.php
/config.php
/lib.php
/schema.sql
/INSTALL.md
/assets
/uploads
```

> Важно: **не меняйте корневую директорию** и не переносите backend в подкаталоги. Всё должно работать из корня домена.

## 2. Создание базы данных в Beget

1. В панели Beget откройте **MySQL базы данных**.
2. Создайте базу данных и пользователя.
3. Сохраните данные: имя БД, пользователь, пароль, хост (обычно `localhost`).

## 3. Настройка `config.php`

Откройте файл `config.php` и заполните параметры:

```php
'db' => [
    'driver' => 'mysql',
    'host' => 'localhost',
    'port' => '3306',
    'name' => 'ВАША_БАЗА',
    'user' => 'ВАШ_ПОЛЬЗОВАТЕЛЬ',
    'pass' => 'ВАШ_ПАРОЛЬ',
    'charset' => 'utf8mb4',
],
'app' => [
    'url' => 'https://ваш-домен.ру',
    'support_email' => 'support@ваш-домен.ру',
],
```

## 4. Импорт базы данных

1. В панели Beget откройте **phpMyAdmin**.
2. Выберите созданную базу данных.
3. Откройте вкладку **Импорт**.
4. Загрузите файл `schema.sql`.
5. Нажмите **Вперёд**.

## 5. Настройка платежей Тинькофф СБП + фискализация

В `config.php` заполните блок `tinkoff`:

```php
'tinkoff' => [
    'terminal_key' => 'TERMINAL_KEY',
    'password' => 'PASSWORD',
    'notification_url' => 'https://ваш-домен.ру/api.php?action=tinkoff_callback',
    'success_url' => 'https://ваш-домен.ру/index.php?page=payments&status=success',
    'fail_url' => 'https://ваш-домен.ру/index.php?page=payments&status=fail',
    'taxation' => 'usn_income',
    'vat' => 'none',
],
```

1. В личном кабинете Тинькофф включите **СБП** и **ФФД**.
2. Укажите URL уведомлений: `https://ваш-домен.ру/api.php?action=tinkoff_callback`.
3. Проверьте, что фискализация включена, а ставка НДС задана корректно.
4. Все чеки сохраняются в таблице `receipts`.

## 6. Проверка оплаты

1. Зарегистрируйте пользователя.
2. Перейдите на страницу **Тарифы** и инициируйте оплату.
3. После успешной оплаты и фискализации подписка активируется автоматически.
4. В разделе **Платежи и чеки** появится запись.

## 7. Создание администратора

1. Зарегистрируйте пользователя.
2. В phpMyAdmin выполните запрос:

```sql
UPDATE users SET role = 'admin' WHERE email = 'ваш-email@домен.ру';
```

Админка доступна в интерфейсе после повторного входа.

## 8. Типовые ошибки и решения

**Ошибка подключения к БД**
- Проверьте параметры в `config.php`.
- Убедитесь, что пользователь БД имеет права на базу.

**Платёж не создаётся**
- Проверьте TerminalKey и Password.
- Проверьте доступность `api.php?action=tinkoff_callback`.
- Проверьте, что домен совпадает с указанным в Тинькофф.

**Фискализация не проходит**
- Проверьте настройки ФФД и НДС.
- Убедитесь, что email покупателя передаётся корректно.

**Не приходит письмо восстановления**
- Уточните настройки SMTP. По умолчанию используется `mail()`.

## 9. Готово

Сервис Kapouch полностью готов к работе и приёму реальных платежей.

Рекомендуется:
- создать резервную копию базы данных,
- настроить HTTPS,
- добавить корпоративный почтовый домен для рассылки.
